# Michess Client & App

This directory contains the core source code for the Michess web application.

For complete documentation, features, architecture, and setup instructions, see the main [Root README](../README.md).

## Quick Commands

- `npm run dev` - Start the local Vite development server
- `npm run build` - Typecheck and build production bundle
- `npm run preview` - Preview production build
- `node --test tests/*.test.mjs` - Run unit test suites
